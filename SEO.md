## Performance measurement

The first Lighthouse run is **not done** because there is no new production deploy
from this tree yet. Run it after the publish, then record the four scores and page
weight here for `/` and `/icons/`:

```bash
npx -y lighthouse@12.8.2 https://artbase-olive.vercel.app/ \
  --only-categories=performance,accessibility,best-practices,seo \
  --output=json --output-path=artifacts/lighthouse-home.json \
  --chrome-flags="--headless --no-sandbox"
```

Do not add Lighthouse to CI; the network-dependent scores are noisy. Fix only a
measured regression, not a speculative one.
