## Performance measurement

Measured on 14 November 2026 against production commit
`5e9abf2a159ec2c6b430d6ddcb3591bda58578e5` with Lighthouse 12.8.2, mobile
preset:

| Page | Performance | Accessibility | Best practices | SEO | Page weight |
| --- | ---: | ---: | ---: | ---: | ---: |
| `/` | not reported | 100 | 100 | 100 | 86 KiB |
| `/icons/` | — | — | — | — | — |

Lighthouse records no LCP entry for `/` (`NO_LCP`), so it returns no performance
score. The `/icons/` audit tab crashes (`TARGET_CRASHED`) before any category
completes, including with `--disable-full-page-screenshot`; its cells are left
blank rather than guessed.

The 14 November reveal fix removes the hero's opacity animation, which was
suppressing LCP. A local run on the fixed tree now reports performance 99 with
LCP 1.8 s; the live table above stays the pre-fix measurement until the next
publish.

```bash
npx -y lighthouse@12.8.2 https://artbase-olive.vercel.app/ \
  --only-categories=performance,accessibility,best-practices,seo \
  --output=json --output-path=/tmp/lighthouse-home.json \
  --chrome-flags="--headless=new --no-sandbox --disable-dev-shm-usage"
```

Repeat with `https://artbase-olive.vercel.app/icons/` for the icon index.

Do not add Lighthouse to CI; the network-dependent scores are noisy. Fix only a
measured regression, not a speculative one.
