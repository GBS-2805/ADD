How this page is made

Generated from the history, every time

  • The listIt walks the commits that changed tools/catalog.json and records each version it finds there, so a version this history never shipped cannot appear on the page.
  • The sizegit cat-file -s on the APK blob at that commit: the bytes that actually went out, not a rebuild measured today.
  • The notesTitles and sentences come from the list on the tools page, where each note is checked against the version whose commit first added it.
  • Keeping uppython3 tools/build_releases.py writes this page, and tools/bump_version.py runs it at the end of every release, so the history here cannot fall behind the shelf.
