Compress

Android app · 2.1 · 272,592 bytes

  • What I builtThe whole app: picker flow, preview pipeline, encoder retry loop, queue management, sharing, the settings screen and the launcher icon.
  • DecisionsNo internet permission at all, so "offline" is enforced by the manifest rather than promised in copy. Preview encodes to cache and deletes itself; nothing is written until you press compress.
  • ConstraintPlatform APIs only — no image library, no analytics, no SDK. The APK is under 300 KB because of it.

Icons browser

Web tool · 1,864 icons · two sets

  • What I builtThe fetch pipeline that pulls every free icon, recolours it to currentColor, the filterable grid and the copy-to-clipboard handling.
  • DecisionsThe icons are inlined in the page instead of fetched, so filtering is instant and the page still works with the network off after load. Copy has a manual fallback because browsers refuse the clipboard on plain HTTP.
  • Shared sourceThe same data is published as /data/icons.json, so the phone app will read exactly what the browser shows.

This site

Static site · one palette · JSON catalogs

  • What I builtThe measured layout, one shared stylesheet across seven pages, the JSON builder that re-measures every shipped file, and the render gallery.
  • DecisionsNo framework and no build step for the pages — they are readable HTML. The build only generates what would otherwise be retyped: the icon set and the catalogs.
  • Why it is a databaseBecause the apps need the same facts the pages state. One catalog file feeds both, and the build fails if a page quotes a stale size.

How I work

The rules these were built under

  • Offline firstIf a feature needs the network, it either moves on-device or gets cut.
  • No accountsNothing here asks you to sign in, and nothing collects anything about you.
  • Measured, not guessedThe palette and spacing come from a Figma frame; the sizes on this site come from the files on disk.
