About the work

One paper, one type system, no noise

Three doors, one shelf: the resources live here, the app carries them offline, and the handoff keeps every build, checksum and install note in one public place. The same paper, plum rule and type system run through all of it.

How I work

  • Quiet firstThe work should leave room for the art, not compete with it.
  • Made to be usedEvery screen is built to be handled on a phone, not just looked at.
  • No accountsNothing asks you to sign in, and nothing tracks what you make.
