In the app

The same page, bundled offline

  • Every brandThe left pull-down lists the brands; each one opens its own page with its own catalog.
  • CategoriesThe sets whose vendor publishes categories filter by them beside the name filter; the rest filter by name alone.
  • Live previewPick an icon and it fills the preview tab. Weight, size and surface repaint it as you press, without touching the file.
  • Quiet by defaultThe whole set hides behind one toggle and scrolls inside its own sheet, so the page is a preview rather than a wall of icons.
  • Copy the fileCopy SVG puts the exact markup on the clipboard: 24×24 viewBox, currentColor, no baked weight.
  • OfflineEvery catalog, the pages and Poppins travel inside the APK. No INTERNET permission, so it cannot phone home.

Same files

The app reads what this site serves

  • /data/icons.json606 Lineicons icons with their markup.
  • /data/coolicons.json1,258 Coolicons icons with their markup.
  • /data/phosphor.json1,512 Phosphor icons with their markup.
  • /data/plump.json500 Plump Solid icons with their markup.

Every catalog is generated from its vendor's own source by tools/fetch_icons.py, which also writes these pages. Names and markup cannot drift between the phone and the web, because there is only one copy of each icon.

Install

Three taps and a warning to dismiss

  1. Tap Download Icons 2.10 and let it finish.
  2. Open it, allow installs from this source, then tap Install.
  3. Play Protect may call it unrecognised. That is what a self-signed sideload looks like; choose Install anyway.

Updates keep your place in the browser. Both apps are signed with the same key, so they install and update side by side.
