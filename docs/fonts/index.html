Each sheet lists one family's faces. The three Poppins faces the apps bundle are byte-for-byte copies from app/res/font/; the rest are fetched once by tools/fetch_fonts.py and served from this site.

How it is wired

Two families, no network

  • Siteassets/site.css sets the site's own Poppins faces; this page declares every downloaded style from /data/fonts.json.
  • Appapp/res/font/poppins_regular.ttf, _medium and _semibold, referenced from the layouts.
  • Downloadswoff2 for the web at /assets/fonts/, TTF beside it for Android and desktop.
  • JSON/data/fonts.json lists each family, its faces, both paths and both measured sizes.

A face looks like this in CSS:

@font-face { font-family: "Poppins"; src: url("fonts/poppins-400.woff2") format("woff2"); font-weight: 400; font-display: swap; }
