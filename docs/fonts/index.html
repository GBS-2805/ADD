How it is wired

Three declarations, no network

  • Siteassets/site.css declares the three faces once; every page links that one stylesheet.
  • Appapp/res/font/poppins_regular.ttf, _medium and _semibold, referenced from the layouts.
  • Downloadswoff2 for the web at /assets/fonts/, TTF beside it for Android and desktop.
  • JSON/data/fonts.json lists each face, its weight, both paths and both sizes.

A face looks like this in CSS:

@font-face { font-family: "Poppins"; src: url("fonts/poppins-400.woff2") format("woff2"); font-weight: 400; font-display: swap; }
