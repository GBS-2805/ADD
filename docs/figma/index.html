Figma hand-off

Twenty-two artboards of this site, and the whole set on one canvas.

Each file is the page as Chromium laid it out — text on real baselines, a rect per box, PNG copies of the marks. Poppins is loaded from this site's own font folder, so every file renders in the site's type; the one-canvas file carries the faces inside it, for opening away from the site. Drag one into a Figma document to get editable layers; enable the Poppins family once there and run Frame selection to lock the artboard's size.
