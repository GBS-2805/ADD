Figma hand-off

45 artboards of this site, and the whole set on one canvas.

Each file is the page as Chromium laid it out — text on real baselines, a rect per box, PNG copies of the marks. Poppins 400/500/600 is embedded in every file, so each one renders in the site's type wherever it is opened, not in the viewer's fallback sans. Drag one into a Figma document to get editable layers; enable the Poppins family once there and run Frame selection to lock the artboard's size.
