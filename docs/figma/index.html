Figma hand-off

Twenty-two artboards of this site, and the whole set on one canvas.

Each file is the page as Chromium laid it out — text on real baselines, a rect per box, PNG copies of the marks. Poppins 400/500/600 travels inside every file, so it looks the same here as in Figma. Drag one into a Figma document to get editable layers; enable the Poppins family once there and run Frame selection to lock the artboard's size.
