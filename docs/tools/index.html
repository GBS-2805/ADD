Icons

Download the app

Android 8.0+ · all ABIs No permissions at all 4,373 icons

The browser you can use here without installing is /icons/; the APK is that same page, its stylesheet, Poppins and both catalogs, wrapped in a WebView that serves them from a private origin inside the app. Nothing is fetched, because the app cannot fetch: there is no INTERNET permission in the manifest.

What it does

A preview, three controls, one sheet

  • Brand pull-downThe chevron lists the four brands — Lineicons, Coolicons, Phosphor and Streamline — and each opens its own page with its own catalog.
  • Live previewThe selected icon sits in its own tab. Weight, size and surface repaint it as you press; the file itself never changes.
  • Quiet setAll 4,373 icons live behind one toggle and scroll inside their own sheet, so the page reads as a preview rather than a wall.
  • CopyCopy SVG hands over the exact file: 24×24 viewBox, currentColor, no baked size or weight.
  • OfflineAll four catalogs, the pages and the fonts travel inside the APK. One palette, Poppins, hairline rules — the same system as this site.

The app reads the catalogs this site publishes under /data/ — Lineicons and Coolicons in one file, Phosphor and each Streamline style in their own — bundled at build time by ./build.sh, so the phone cannot drift from the web.

Compress

3.0 · app.offline.compress · in the app

Download the app

Android 8.0+ · arm64 & x86 No ads · no account Compressor

Built for a Galaxy Z Flip 7 (Android 16). Signed, no third-party libraries, adaptive launcher icon. The checksum is on the download page.

What it does

Four screens, no account

  • Real qualityPick a level; the encoder retries lower until the file actually gets smaller.
  • DownscaleCap the longest edge at 1280, 1920, 2560, 3200 or 4096 px, or keep the original.
  • Batch itUp to 40 photos, per-file savings, then share them all in one go.
  • Share inCompress sits in Android's own share sheet: send it a photo, or a batch, from any gallery or camera app and it lands in the queue.
  • OrientationEXIF rotation is applied to the pixels, so portrait shots stay upright.
  • MetadataLocation and device tags are dropped during re-encode.
  • Non-destructiveCopies go to Pictures/Compress; originals are untouched.
  • VerifyTapping a saved result reopens the slider so you can confirm the file matches the preview.

Install

Five taps, then never again

  1. Tap Download the app and wait for it to finish — one small file.
  2. Open it from the notification shade, or Files → Downloads.
  3. Android says the install is blocked: tap Settings, enable Allow from this source, then go back.
  4. Tap Install → Open. If Play Protect warns about an unknown developer, choose Install anyway.
  5. Updating from an earlier build keeps your data — same signing key, higher version code.

These are self-signed builds, so Play Protect may call them unrecognised. That is expected for a build installed outside the Play Store, not a sign of tampering.
