Install on Android

Five taps, then never again

  1. Tap one of the download buttons above and wait for it to finish — both are small.
  2. Open the file from the notification shade, or Files → Downloads.
  3. Android says the install is blocked: tap Settings, enable Allow from this source, then go back.
  4. Tap Install → Open. If Play Protect warns about an unknown developer, choose Install anyway.
  5. Updating from an earlier build keeps your data — same signing key, higher version code.

These are self-signed builds, so Play Protect may call them unrecognised. That is expected for apps installed outside the Play Store, not a sign of tampering. Compare the SHA-256 below if you want to be sure a file arrived intact.
