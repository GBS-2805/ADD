How it works

Two taps in the app, or one file here

  1. In ADD, open Editor → the font button → Font packs…. The app loads this page’s packs.json.
  2. Tap Download beside a family. The pack is saved on the phone; the family appears in the font list and stays there offline.
  3. Come back to Update or remove a family. A file downloaded from this page can still be imported from the same screen.

Each pack is signed with ECDSA P-256. The app checks that signature and a SHA-256 for every file before it installs anything, so a corrupted or altered download is refused. Opening Font packs reads the list saved on the phone; it fetches that list only when nothing is saved, and a pack only when you tap Download.

What is inside

A manifest, the TTFs, and their hashes

  • manifest.jsonSchema, kind, slug, family, version, licence, source, every style with its file, and every file with its bytes and SHA-256.
  • VersionDerived from the file hashes: change a TTF and the pack gets a new name, so a cached download cannot be mistaken for the new one.
  • ChecksThe app refuses a pack with a bad signature, an unexpected entry, a path it does not like, a size over the cap, or a hash that does not match — and leaves the previous install alone.
  • manifest.sigAn ECDSA P-256 signature over the exact manifest bytes. The public key ships inside ADD; the private key never enters this site or the repository.
